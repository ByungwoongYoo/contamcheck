# Examples

Three small, fully synthetic tables (no real data), generated by [`make_examples.py`](make_examples.py) with a fixed seed. Each one is a different kind of provenance problem.

| file | story | label | group column | other candidate columns | expected verdict |
|---|---|---|---|---|---|
| `clean_manufacturing.csv` | injection-moulded parts from 60 production batches on 4 lines; batches differ in process offsets, but batch says nothing about the label | `defect` (0/1) | `batch` | `line` | CLEAN |
| `watch_materials.csv` | thin-film samples compiled from 70 source papers; each paper studied a skewed (but mixed) set of samples, the features carry a real signal | `conductive` (yes/no) | `source_paper` | — | WATCH |
| `contaminated_measurement.csv` | alloy coupons from 48 corrosion-test campaigns; each campaign mostly tested one class on one of 8 instruments, whose calibration shifts the features | `corrosion_pass` (0/1) | `campaign` | `instrument`, `lab` | CONTAMINATED |

Run all three (from the repository root, after `pip install -e .`):

```bash
bash examples/run_examples.sh out/examples
```

or one at a time:

```bash
contamcheck --input examples/clean_manufacturing.csv      --label-col defect         --group-col batch        --out out/clean
contamcheck --input examples/watch_materials.csv          --label-col conductive     --group-col source_paper --out out/watch
contamcheck --input examples/contaminated_measurement.csv --label-col corrosion_pass --group-col campaign     --out out/contaminated
```

## Expected output

Stored in [`expected/`](expected/) (`<name>.log` is the console output, `<name>/report.md|json` the full report). Produced with Python 3.13.5, numpy 2.5.4, pandas 3.1.0, scikit-learn 1.9.1, default seed 20261101; other library versions may move the last digits, not the verdicts.

| example | group-alone AUC [95% CI] | groups single-label | random-split AUC (mean of 10) | grouped AUC | delta grouped − random [95% CI] | verdict |
|---|---|---|---|---|---|---|
| clean_manufacturing | 0.4558 [0.4235, 0.4877] | 0.0 | 0.7932 | 0.7898 | −0.0023 [−0.0056, 0.0008] | CLEAN (0) |
| watch_materials | 0.8077 [0.7799, 0.8334] | 0.0714 | 0.9847 | 0.9852 | +0.0005 [−0.0002, 0.0013] | WATCH (1) |
| contaminated_measurement | 0.9415 [0.9258, 0.9547] | 0.1667 | 0.6165 | 0.4577 | −0.1591 [−0.1771, −0.1414] | CONTAMINATED (2) |

- **clean**: the batch carries no label information (AUC under 0.5 is the expected leave-one-out effect) and the classifier scores the same either way.
- **watch**: papers are label-skewed (group-alone AUC 0.8077 ≥ 0.70), but no paper is single-label and the feature signal transfers across papers, so grouped CV loses nothing. One flag: report grouped CV, but the model looks sound.
- **contaminated**: the campaign gives the label away, and the classifier falls from 0.6165 to 0.4577 when campaigns are held out — its random-split skill was recognising instruments.
